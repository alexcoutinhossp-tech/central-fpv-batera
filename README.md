# Central FPV — Batera

PWA inicial, responsiva e instalável no iPhone como app da tela inicial.

## Publicar
1. Hospede o conteúdo desta pasta em um endereço HTTPS (por exemplo, GitHub Pages ou outro serviço de hospedagem estática).
2. Abra o endereço no Safari do iPhone.
3. Toque em Compartilhar > Adicionar à Tela de Início.

## Importante
- Esta é uma base inicial de consulta, não se conecta ao rádio nem lê telemetria ao vivo.
- Os dados marcados como pendentes precisam ser confirmados no equipamento.
- Não use valores de configuração como substituto de checagem pré-voo.
